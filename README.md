# servimuebles
Sitio web de Servimuebles, empresa dedicada a la venta de muebles para el hogar, desarrollado con HTML5, CSS3 y JavaScript por la División Tecnova Web de Tecnova. Diseño moderno, adaptable a dispositivos móviles y orientado a ofrecer una experiencia de navegación intuitiva, destacando los productos y servicios de la empresa.
